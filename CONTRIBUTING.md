# Contributing

Thank you for improving the SMSFlow Node.js SDK.

Before submitting changes:

- Do not include real SMSFlow credentials, bearer tokens, phone numbers, logs, or customer data.
- Keep server-side usage clear; SMSFlow Client Secrets must not be exposed in browser JavaScript.
- Add or update tests for behavior changes.
- Run `npm test` before opening a pull request.

Documentation: https://docs.smsflow.co.za/
