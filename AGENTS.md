# smsflow-node Agent Instructions

This repository is intended to become the public Node.js SDK for SMSFlow.

- Do not commit real SMSFlow credentials, phone numbers, tokens, customer data, or npm publishing tokens.
- Keep SDK code dependency-light and easy to use from backend Node.js applications.
- Do not support browser-side usage for credentialed API calls.
- Use `.env.example` only for placeholder local configuration.
